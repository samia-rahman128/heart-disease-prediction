# Project Name: Interpretable Multi-Model Machine Learning System for Heart Disease Prediction

- *Course:* CSE431 (Machine Learning)
- *Group:* Group 03
- *Domain:* Healthcare

## Project Overview
This project develops an interpretable multi-model machine learning pipeline to predict cardiovascular disease risk using clinical and lifestyle features. By integrating explainability techniques (such as SHAP/LIME) alongside predictive models, the system aims to provide transparent risk insights.

> *Disclaimer:* Educational prototype, not a medical device.
